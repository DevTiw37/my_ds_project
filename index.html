Core Architecture & Design

1. DataLoader (src/loader.py) Handles ingestion of raw CSV datasets with integrated exception handling and execution logging.
2. DataCleaner (src/cleaner.py) Stateless transformer that eliminates duplicate records and imputes missing numeric values using clean medians.
3. FeatureTransformer (src/transformer.py) Scikit-learn compatible wrapper (BaseEstimator, TransformerMixin) that applies StandardScaler and OneHotEncoder safely.

Pipeline Orchestrator (main.py)

End-to-End Execution Flow 
import pandas as pd
from src.loader import DataLoader
from src.cleaner import DataCleaner
from src.transformer import FeatureTransformer

class DataPipeline:
    def __init__(self, file_path: str):
        self.loader = DataLoader(file_path)
        self.cleaner = DataCleaner()
        self.transformer = FeatureTransformer()

    def run_pipeline(self, output_path: str | None = None) -> pd.DataFrame:
        raw_data = self.loader.load_data()
        cleaned_data = self.cleaner.fit_transform(raw_data)
        processed_data = self.transformer.fit_transform(cleaned_data)
        
        final_df = pd.DataFrame(processed_data)
        if output_path:
            final_df.to_csv(output_path, index=False)
        return final_df
